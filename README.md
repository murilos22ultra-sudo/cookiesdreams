# COOKIE DREAM - Gestão de Custos

Aplicativo web responsivo para gestão dos custos de receitas e produção de cookies.

## Publicar no GitHub Pages

1. Crie um repositório novo no GitHub.
2. Extraia o arquivo ZIP no computador.
3. Envie para o repositório os arquivos `index.html`, `.nojekyll` e `README.md`.
4. No repositório, abra **Settings > Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch **main** e a pasta **/(root)**.
7. Clique em **Save**.

Após alguns minutos, o endereço público será exibido na seção GitHub Pages.

## Dados

As receitas ficam salvas no `localStorage` do navegador. Portanto, os dados permanecem no mesmo navegador e aparelho, mas não são sincronizados automaticamente entre dispositivos.

## Arquivos

- `index.html`: aplicativo completo.
- `.nojekyll`: evita processamento desnecessário pelo Jekyll.
- `README.md`: instruções do projeto.
